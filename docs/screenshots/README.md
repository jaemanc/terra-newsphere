# README 화면 캡처

- 캡처일: 2026-10-16.
- 환경: Google Chrome의 실제 로컬 앱. 기존 6장은 `http://127.0.0.1:8080`의 한국어 UI, 추가 `07-news-overview.png`는 현재 프런트 소스를 실행한 개발 서버의 영어 UI다.
- 크기: 기존 데스크톱 1440×960, 모바일 390×844, 추가 뉴스 개요 1680×1050.
- 범위: 메인, 사이드바 접기, 국가 선택, 실제 마커 호버, 마커 클릭 카드, 모바일 지도, 뉴스가 많은 지구본 개요.
- 데이터: 기존 6장은 브라우저의 뉴스 API 응답만 문서용 가상 기사 15건으로 대체했다. 제목에 `예시`, 출처에 `TerraNewsphere 데모`를 표시하고 상세 카드에는 데모 배지를 유지했다. 추가 개요는 가상 기사 579건이며 제목에 `DEMO`, 출처에 `TerraNewsphere Demo`를 표시했다. 카메라 시점을 조정해 헤드라인 32개가 보이는 화면을 캡처했으며 앱의 클러스터·헤드라인 숨김 규칙은 바꾸지 않았다. 서버의 뉴스·Redis·Kafka·수집기는 변경하지 않았다.
- 이미지: 기사 썸네일은 저장소의 `frontend/public/images/fallback.svg`다. 실제 기사·출판사 이미지나 사용자 계정·브라우저 화면은 포함하지 않았다.
- 지도: NASA Blue Marble, Natural Earth, geoBoundaries 및 OpenStreetMap 배경을 실제 화면대로 캡처했다. 화면의 출처 표시를 보존했으며 [지리 데이터 문서](../geography.md)의 출처·라이선스를 따른다.
- 확인: 호버와 클릭 카드, 원문 링크의 `noopener noreferrer`, 모바일 가로 넘침 없음, 페이지 오류 0개. 문서용 응답을 사용했으므로 이 캡처는 실뉴스 수집·API·파이프라인 검증 결과를 대신하지 않는다.
