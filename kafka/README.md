# Kafka

`apache/kafka:4.0.2`, KRaft 브로커/컨트롤러 한 개와 `news.raw` 토픽 하나를 사용한다.
`create-topic.sh`는 Compose 초기화 서비스와 K3s Job에서 사용한다.

토픽은 파티션 1개, 복제 1개, 시간 24시간·크기 512MiB 보존 한도를 둔다. 삭제는 세그먼트 정리 주기에 따라 실행되므로 정확한 시각의 삭제를 의미하지 않는다. Redis 기사 만료와 별개의 정책이다.
포트는 내부 네트워크에만 노출한다. 호스트 Python에서 접근하려면 개발용 별도 리스너가 필요하며 기본 실행은 컨테이너 내부에서 한다.
